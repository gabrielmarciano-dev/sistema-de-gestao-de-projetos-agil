# Restrições (RES)

[Voltar ao README](../readme.md)

Limitações impostas ao projeto relacionadas a tecnologia, prazo e aspectos legais.

---

## RES01 — Tecnologia Open Source

| Campo | Detalhe |
|---|---|
| **Restrição** | O sistema deve ser desenvolvido com tecnologias de código aberto (*Open Source*). |
| **Categoria** | Tecnologia |
| **Justificativa** | Redução de custos com licenças proprietárias e flexibilidade técnica. |

---

## RES02 — Prazo de entrega

| Campo | Detalhe |
|---|---|
| **Restrição** | O sistema deve ser finalizado e entregue para testes até a data limite estipulada no cronograma. |
| **Categoria** | Prazo |
| **Justificativa** | Cronograma de entregas da disciplina acadêmica. |

---

## RES03 — Conformidade com a LGPD

| Campo | Detalhe |
|---|---|
| **Restrição** | O tratamento e armazenamento de dados pessoais de saúde deve estar rigorosamente em conformidade com a **LGPD**. |
| **Categoria** | Legal |
| **Justificativa** | Cumprimento das obrigações legais federais relativas à privacidade de dados. |
| **Requisito de qualidade relacionado** | [RQ02 — Segurança](requisitos-qualidade.md#rq02--segurança) |
